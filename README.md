## Installation

**Installation via requirements.txt**

**Windows**
```shell
$ cd CS235-SampleWebApp-CovidNewsPortal
$ py -3 -m venv venv
$ venv\Scripts\activate
$ pip install -r requirements.txt
```

**MacOS**
```shell
$ cd CS235-SampleWebApp-CovidNewsPortal
$ python3 -m venv venv
$ source venv/bin/activate
$ pip install -r requirements.txt
```
